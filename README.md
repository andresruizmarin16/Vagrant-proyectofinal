# Proyecto Final

Este proyecto consiste en una infraestructura automatizada utilizando:
- **Vagrant**: Para la gestión de máquinas virtuales.
- **Ansible**: Para la automatización de la configuración.
- **Docker**: Para el despliegue de servicios.

## Requisitos
- Vagrant
- Ansible
- Docker

## Instrucciones
1. Clona este repositorio.
2. Ejecuta `vagrant up` para levantar las máquinas virtuales.
3. Accede a los servicios en las IPs configuradas.
